## 📸 Portfolio Preview & Theme

The portfolio is designed with a **Cyber-Slate & Emerald Glassmorphism** visual language:
- **Backgrounds:** Deep space slate (`#0B0F17`) with elevated card layers (`#141C2B`).
- **Accents:** Emerald green (`#10B981`), Cyber Indigo (`#6366F1`), and Electric Cyan (`#06B6D4`).
- **Typography:** Modern pairing of `Outfit` (display headers), `Inter` (body copy), and `Fira Code` (technical tags).
- **Responsiveness:** Fully adaptive CSS grid and flexbox layout supporting ultra-wide monitors, laptops, tablets, and smartphones.

### 1. 🗂️ Interactive Project Filtering
The projects section includes dynamic category switching driven by vanilla JavaScript data attributes:
* **All Projects:** Complete repository gallery.
* **Full Stack:** Enterprise Spring Boot, React 18, and Supabase applications.
* **AI & Machine Learning:** Multi-agent systems, Gemini 2.0 pipelines, and Cloud Run agents.
* **Python & Systems:** Cryptographic verifiers, CLI calculators, and data extraction pipelines.

### 2. 📖 Technical Publications Hub
Dedicated showcase cards linking directly to published engineering articles on Medium:
* **Article 1:** *Building an Autonomous 4-Agent Pipeline with Google Gemini 2.0 Flash and Server-Sent Events*
* **Article 2:** *Engineering an Anti-Cheating Online Examination Engine with Spring Boot 3 & Java 21*

## 🛠️ Local Development & Preview

To run or modify the portfolio locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ranjithbrs/portfolio.git
   cd portfolio
   ```

2. **Open in any modern web browser:**
   * **Direct File Open:** Double-click `index.html` in your file explorer.
   * **VS Code Live Server:** Right-click `index.html` $\to$ **Open with Live Server**.
   * **Python Simple Server:**
     ```bash
     python -m http.server 8000
     ```
     Navigate to `http://localhost:8000` in your browser.
